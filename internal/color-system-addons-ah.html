Addon roles

RoleTokenMeaning
Essential--addon-importance-essentialStrongest recommendation for the selected context.
Recommended--addon-importance-recommendedHigh-value recommendation that is not mandatory.
Optional--addon-importance-optionalUseful preference or specialized tool.
Tested--addon-compatibility-testedConfirmed compatibility state using global success.
Caution--addon-compatibility-cautionKnown caveat using global warning.
Broken--addon-compatibility-brokenConfirmed failure using global danger.
Separation rule: importance answers “how useful is it?” Compatibility answers “does it work?” One badge must never silently answer both.

Component rules

Search and focus use section identity

Addons use periwinkle. AH uses ledger teal.

Market data uses market roles

Target, Quick, and High colors do not become generic decoration.

Demand uses labels and structure

Demand levels remain readable without a rainbow badge system.

Mobile selection highlights one card

The entire AH row-card receives one continuous selected treatment.

Warnings remain global

Price caveats and compatibility cautions use fixed status tokens.

Item quality remains canonical

AH identity never recolors item rarity.

Boundaries and related references

Do not borrow class colors: an Addon useful for a Paladin does not become Paladin pink, and an AH item for a Death Knight does not become crimson.
