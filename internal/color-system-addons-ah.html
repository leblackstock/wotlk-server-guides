Addons + Auction House Color Standard

The section identities, component meanings, market-data colors, and implementation boundaries that extend the shared WotLK guide system beyond class guides.

Rules Addon roles AH roles Boundaries

Four color layers

Every color decision must belong to one layer. Components may combine layers, but a color never changes meaning merely because it appears in another section.

1

Foundation

Surfaces, text, borders, table heads, and code backgrounds are shared across the entire site.

2

Global meaning

Success, warning, danger, information, and site navigation keep fixed meanings everywhere.

3

Identity

Addons and Auction House receive restrained section accents without borrowing class or status colors.

4

Local data

Recommendation levels, price lanes, demand, and other data roles use named tokens within their domain.

Implementation rules

Central token ownership

Foundation, navigation, status, section identities, recommendation roles, market roles, class/spec identity, and WoW game-data colors live in assets/guide-color-system.css.

Component ownership

Layout and component geometry remain in addon-catalog.css, style.css, or the AH section stylesheet. Components consume named roles rather than copying hex values.

Section activation

Use data-guide-section="addons" or data-guide-section="auction-house". Auction House pages also use data-ah-guide only for genuine page-specific exceptions.

Accessibility

Every state retains text, icons, shape, or block count. Color supports meaning but never becomes the only instruction.

Auction House table system

Standard market

Item → Target Price → Quick Price → High / Scarce → Stack Size → Demand → Use / Selling Notes.

Extended market

Uses the same first four columns, then adds Market and Source before demand and notes for recipe and pattern drops.

Compact reference

Uses ah-reference-table for vendor rules, conversions, inputs, fixed values, and other non-market references.

Mobile behavior

Below 760px, rows become cards. Item and Target Price stay first and span the card width.
