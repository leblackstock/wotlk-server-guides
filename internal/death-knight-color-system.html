Frost and Unholy implementation boundary

Frost is identity-ready

The glacial accent is approved for selected navigation and Frost-only emphasis. Do not copy Blood component choices blindly; define Frost’s recurring proc, weapon, and priority lanes when its guide is built.

Unholy is identity-ready

The necrotic accent is approved for selected navigation and Unholy-only emphasis. Shared diseases and minions keep their existing mechanic colors, while future Unholy-specific decision lanes require explicit approval.

No placeholder mechanic colors: Frost and Unholy guides should reuse shared DK mechanics first and add new semantic lanes only when recurring gameplay concepts genuinely require them.

Semantic boundaries

Class crimson is not Blood

Broad DK framing uses the class token. Blood selection uses the brighter specialization token.

Blood is not danger

Danger retains the global status token and explicit failure wording.

Frost is not information

Frost uses its named specialization tokens, not the global information color.

Unholy is not success

Necrotic yellow-green remains labeled and structurally separate from success green.

Diseases are not Unholy

The disease lane remains shared across all Death Knight specializations.

Minions are not automatically Unholy

Ghoul, Army, and Death Pact use the shared minion language wherever they appear.
