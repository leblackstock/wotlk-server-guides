Death Knight Color System

The production contract for one Death Knight class identity, three clearly separated specialization accents, and a shared resource language that remains stable across every DK guide.

Rules Class Specs Mechanics Components Accessibility

◆ Hierarchy rules

1. Crimson identifies the class

The official Death Knight crimson frames titles, class notes, broad links, and shared DK identity. It is not the Blood spec state by itself.

2. The active spec owns controls

Blood, Frost, or Unholy colors own selected navigation, filter state, focused cards, and specialization-specific technical emphasis.

3. Resources keep one language

Runes, Runic Power, diseases, and minions use the same mechanic colors in every spec so diagrams remain learnable.

4. Status colors stay global

Warning amber, danger salmon, success green, and information cyan never become DK decoration.

5. Schools are not a rainbow

Do not assign a new color to every spell school or ability. Color repeated decisions and relationships, not every button.

6. Labels carry the meaning

Every colored state also uses text, an icon, border, position, or pressed state. Color is reinforcement, never the only signal.

Class name, shared DK notes, broad identity, shared page framing, and links that apply to all three specs.

Do not: flood whole pages with red or use class crimson for danger, failed mechanics, or every damage ability.

◆ Accessibility and regression gate

  • Blood red is differentiated from danger by hue, component placement, and explicit labels.
  • Frost blue is less cyan than the site information color and is never used for generic informational notes.
  • Unholy is yellow-green rather than success green; success still uses the fixed global token.
  • All selected controls require borders, pressed state, focus treatment, or wording in addition to color.
  • Dark, mobile, reduced-motion, and black-and-white print views must preserve hierarchy.
  • Future DK guides must consume these tokens rather than introducing raw hex values in page HTML.
