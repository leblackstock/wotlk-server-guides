Death Knight class identity

Death Knight crimson

Class title, broad Death Knight framing, class-wide notes, and links shared by all three specs.

What crimson does not own

Blood selected state, danger warnings, disease tracking, runes, Runic Power, minions, or item rarity.

Rule: Blood must look related to the class without making every Death Knight page look like Blood.

Shared-language rule: a rune remains rune-blue on Blood, Frost, and Unholy pages. The active spec changes the controls around the mechanic, not the mechanic's identity.

Semantic boundaries

Class crimson is not Blood

Broad DK framing uses the class token. Blood selection uses the brighter spec token.

Blood is not danger

Danger retains the global status token and explicit failure wording.

Frost is not information

Frost uses its named specialization tokens, not the global info color.

Unholy is not success

The necrotic yellow-green remains labeled and structurally separate from success green.

Mechanics survive spec swaps

Runes, Runic Power, diseases, and minions do not change color by spec.

Status and rarity stay global

Warnings, danger, item quality, and sockets remain untouched.
