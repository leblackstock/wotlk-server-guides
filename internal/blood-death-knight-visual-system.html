Assignment:

Release rules

  • Class red identifies Death Knights; Blood rose identifies this spec and active navigation.
  • Cyan, teal, gold, and violet are restricted to runes, Runic Power, diseases, and minions.
  • Warning and danger remain global semantic states; class colors never replace them.
  • Normal body copy uses the shared text palette. Soft accents are links or short emphasis, not paragraph text.
  • Focus outlines, labels, icons, patterns, and explicit state text keep every control usable without color perception.
  • Desktop, mobile, print, hover, focus-visible, and forced-colors behavior are part of the final regression check.
