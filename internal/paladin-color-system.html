Paladin Color System

Paladin pink remains the shared class identity. Protection, Holy, and Retribution receive separate specialization colors so selected state never erases the family resemblance.

Paladin class identity

Paladin pink

Class title, broad Paladin framing, class notes, and links that remain Paladin-wide.

--class-paladin-accent: #f58cba
What pink does not own

Selected spec controls, warning state, healing relationships, rotation timing, item quality, or global navigation.

Rule: every Paladin page should still look related when the active spec accent changes.

Specialization comparison

Protection

Steel blue for selected chapters, filters, tank-specific controls, mitigation state, and Protection-only emphasis.

Protection
#6f9fe8 · --spec-paladin-protection-accent

Holy

Warm gold for selected chapters, healing controls, Holy-specific labels, focus state, and technical emphasis.

Holy
#e6be4a · --spec-paladin-holy-accent

Retribution

Warm martial red for selected chapters, offensive controls, priority-state emphasis, and Retribution-only identity.

Retribution
#e06b65 · --spec-paladin-retribution-accent
Why combine them here: reviewing all three together exposes drift immediately. A spec can be distinctive without stealing the class layer or colliding with a fixed status color.
