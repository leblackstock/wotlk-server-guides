Recommended updater

Keep Git-hosted addons updated with GitAddonsManager

GitAddonsManager installs and updates addons directly from GitHub, GitLab, and similar Git repositories. It is the recommended way to install Auctioneer Revisited, RandomCompanions, and other addons for which this guide provides a .git clone URL.

Important: GitAddonsManager only works with addons that are also Git repositories. It cannot manage an ordinary ZIP-only or manually installed addon unless its maintainer provides a compatible Git clone URL.
Download GitAddonsManager from the official page ↗
Installation, setup, adding addons, and updating addons

1. Install GitAddonsManager on Windows

  1. Exit World of Warcraft completely before installing or updating addons.
  2. Open the official GitAddonsManager page above and select Download for Windows x64.
  3. Extract the downloaded ZIP into a permanent tools folder. Do not run the application from inside the ZIP.
  4. Open the extracted folder and run GitAddonsManager. Keep the folder in place so its files remain available the next time you update addons.

2. Point it at the correct WoW installation

  1. On first launch, choose the folder that directly contains your addons. It normally ends in World of Warcraft\Interface\AddOns; a private-server launcher may instead use a path ending in launcher\Interface\AddOns.
  2. Confirm you selected Interface\AddOns itself—not Interface, the game root, or one individual addon folder.
  3. If you maintain more than one WoW installation, open Options, select Add directory, and add each installation's separate Interface\AddOns folder.

3. Add an addon from a repository

  1. Back up any existing copy and its important files under WTF\Account\<account>\SavedVariables. Remove or move old addon folders out of Interface\AddOns so releases cannot mix.
  2. Open GitAddonsManager's Addons tab and select the + button labeled Download a new addon from a git repository.
  3. In Clone Repository, paste the repository's clone URL, which normally ends in .git. Use https://github.com/leblackstock/auctioneer-revisited-wotlk.git for Auctioneer Revisited or https://github.com/leblackstock/RandomCompanions-WotLK.git for RandomCompanions.
  4. If more than one AddOns directory is configured, choose the correct destination, select OK, and wait for cloning and subfolder setup to finish.
  5. For Auctioneer Revisited, confirm Interface\AddOns\Auc-Advanced\Auc-Advanced.toc and Interface\AddOns\BeanCounter\BeanCounter.toc exist directly under AddOns. Do not leave the suite nested inside another folder.
  6. For RandomCompanions, confirm GitAddonsManager used the root TOC name and created Interface\AddOns\RandomCompanions\RandomCompanions.toc. Do not leave it under RandomCompanions-WotLK or another nested folder.
  7. Start WoW, enable Load out of date AddOns if the client requests it, and verify the addon version and settings before normal play.

4. Check for and install addon updates

  1. Exit WoW, open GitAddonsManager, and select Refresh addons list and check for updates.
  2. Use the update button beside one addon when its tooltip says Perform upgrade, or select Upgrade all addons in the toolbar.
  3. Wait until the manager reports that the operation has finished, then start WoW and confirm the expected addon version still loads.
  4. Keep SavedVariables unless an addon's own upgrade instructions explicitly require a reset; that is where Auctioneer market history and BeanCounter records are stored.
Know the limits: GitAddonsManager does not search for addons and does not automatically detect addons installed manually without a .git repository. Only use clone URLs supplied by a trusted addon source, and keep backups because repair or update operations can replace local file edits.

Detailed setup

GitAddonsManager installation and maintenance

Use this walkthrough when setting up GitAddonsManager for the first time, moving an existing addon under Git management, or recovering from a failed clone or update.

Open the official download page ↗

Before you start

  • Exit World of Warcraft before changing addon files. Keep a backup of important addon folders and account SavedVariables.
  • GitAddonsManager only works with addons that are also Git repositories. It does not search for addons or automatically adopt ordinary ZIP installations without a .git repository.
  • Use trusted HTTPS clone URLs supplied by the addon maintainer. A clone URL normally ends in .git.

1. Download and launch it on Windows

  1. Open the official page above and choose Download for Windows x64.
  2. Extract the ZIP into a permanent tools folder. Do not run the executable from inside the compressed ZIP.
  3. Launch GitAddonsManager from the extracted folder. Keep the entire extracted folder together so the application can update and reopen normally.

2. Select the exact AddOns directory

  1. When Choose addons directory appears, select the folder ending in Interface\AddOns.
  2. A standard installation may end in World of Warcraft\Interface\AddOns. A private-server launcher may use a path ending in launcher\Interface\AddOns.
  3. Do not select the WoW root, Interface, or one individual addon folder. The selected directory must directly contain folders such as Questie, BeanCounter, or Auc-Advanced.
  4. For another WoW installation, open Options, choose Add directory, and add that installation's separate Interface\AddOns folder.

3. Prepare an addon that is already installed

  1. Back up the existing addon folder and any important files under WTF\Account\<account>\SavedVariables.
  2. Move the old addon folder to a backup location outside Interface\AddOns. Merely renaming it inside AddOns can allow WoW to keep loading it.
  3. For a multi-folder suite such as Auctioneer, move every folder belonging to the old matched suite. Mixing old and new modules can cause silent failures.

4. Clone and add an addon

  1. Open the Addons tab and select the + button labeled Download a new addon from a git repository.
  2. In Clone Repository, paste the trusted HTTPS clone URL.
  3. If several AddOns directories are configured, select the intended game installation, then choose OK.
  4. Wait for cloning and subfolder setup to finish. Do not start WoW while the operation is running.
  5. Confirm the addon's .toc file is at Interface\AddOns\AddonName\AddonName.toc, not one folder deeper.

5. Install Auctioneer Revisited

  1. Back up AucAdvanced.lua, AucAdvanced.lua.bak, BeanCounter.lua, and BeanCounter.lua.bak for every account whose scans or sales history matter.
  2. Move the complete old Auctioneer suite outside AddOns, including Auc-Advanced, BeanCounter, Enchantrix, Informant, SlideBar, Stubby, !Swatter, and every Auc-Filter, Auc-ScanData, Auc-Stat, and Auc-Util folder.
  3. Paste https://github.com/leblackstock/auctioneer-revisited-wotlk.git into Clone Repository.
  4. Confirm Interface\AddOns\Auc-Advanced\Auc-Advanced.toc and Interface\AddOns\BeanCounter\BeanCounter.toc exist directly under AddOns.
  5. Start WoW, enable Load out of date AddOns if requested, and confirm the old scans and BeanCounter history load before deleting the backups.
  6. Open Auctioneer Configure → Server Rules. Confirm Hellscream on Hellscream, or switch to Standard WotLK on servers using normal auction rules.

6. Install RandomCompanions

  1. Back up RandomCompanions.lua and RandomCompanions.lua.bak from each account's SavedVariables folder, and move any old RandomCompanions addon folder outside AddOns.
  2. Paste https://github.com/leblackstock/RandomCompanions-WotLK.git into Clone Repository.
  3. GitAddonsManager should use the root RandomCompanions.toc name when arranging the checkout. Confirm the final path is Interface\AddOns\RandomCompanions\RandomCompanions.toc, not a nested RandomCompanions-WotLK folder.
  4. Start WoW, enable Load out of date AddOns if requested, open /rc config, and confirm the previous positions, modes, Favorites, and auto-pet setting loaded.
  5. Run /reload, summon one mount and one pet, and keep the backups until both the full login and reload checks succeed.
  6. To restore the previous installation, exit WoW, remove the Git-managed folder, restore the complete addon-folder backup, and restore the matching RandomCompanions.lua SavedVariables files.

7. Check for and install updates

  1. Exit WoW, open GitAddonsManager, and select Refresh addons list and check for updates.
  2. Use the button beside one repository when its tooltip says Perform upgrade, or use Upgrade all addons in the toolbar.
  3. Wait for the operation to finish, start WoW, and verify the expected addon version. Keep SavedVariables unless the addon maintainer explicitly requires a reset.

8. Repair, remove, or recover an addon

  • Repair: restores repository-managed addon files and may replace local edits.
  • Repair repository: attempts to download the repository again when its Git data is damaged.
  • Delete: removes the managed addon files. Account SavedVariables are separate, but back them up before removing anything important.
  • If an update loses expected data, exit WoW and restore both the addon-folder backup and the matching SavedVariables backup.

Common problems

The addon is not listed
It was probably installed manually without a .git repository. Back it up, move it out of AddOns, and clone it through GitAddonsManager.
Clone Repository reports an error
Confirm the URL is a public HTTPS clone URL ending in .git, the destination is the correct AddOns folder, and no old folder is blocking the repository name.
The addon is nested too deeply
Confirm the selected directory is Interface\AddOns. Use the repository repair option if the manager did not finish arranging its addon subfolders.
No update appears
Select refresh, check the repository's active branch, and review View log for fetch or local-file errors.

Keep the backup: do not delete the old addon and SavedVariables backups until the replacement has loaded successfully after both a full login and /reload.
