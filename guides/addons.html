Recommended updater

Keep Git-hosted addons updated with GitAddonsManager

GitAddonsManager installs and updates addons directly from GitHub, GitLab, and similar Git repositories. It is the recommended way to install Auctioneer Revisited and other addons for which this guide provides a .git clone URL.

Download GitAddonsManager from the official page ↗
Installation, setup, adding addons, and updating addons

1. Install GitAddonsManager on Windows

  1. Exit World of Warcraft completely before installing or updating addons.
  2. Open the official GitAddonsManager page above and select Download for Windows x64.
  3. Extract the downloaded ZIP into a permanent tools folder. Do not run the application from inside the ZIP.
  4. Open the extracted folder and run GitAddonsManager. Keep the folder in place so its files remain available the next time you update addons.

2. Point it at the correct WoW installation

  1. On first launch, choose the folder that directly contains your addons. It normally ends in World of Warcraft\Interface\AddOns; a private-server launcher may instead use a path ending in launcher\Interface\AddOns.
  2. Confirm you selected Interface\AddOns itself—not Interface, the game root, or one individual addon folder.
  3. If you maintain more than one WoW installation, open Options, select Add directory, and add each installation's separate Interface\AddOns folder.

3. Add an addon from a repository

  1. Back up any existing copy and its important files under WTF\Account\<account>\SavedVariables. Remove or move old addon folders out of Interface\AddOns so releases cannot mix.
  2. Open GitAddonsManager's Addons tab and select the + button labeled Download a new addon from a git repository.
  3. In Clone Repository, paste the repository's clone URL, which normally ends in .git. For Auctioneer Revisited, use https://github.com/leblackstock/auctioneer-revisited-wotlk.git.
  4. If more than one AddOns directory is configured, choose the correct destination, select OK, and wait for cloning and subfolder setup to finish.
  5. For Auctioneer Revisited, confirm Interface\AddOns\Auc-Advanced\Auc-Advanced.toc and Interface\AddOns\BeanCounter\BeanCounter.toc exist directly under AddOns. Do not leave the suite nested inside another folder.
  6. Start WoW, enable Load out of date AddOns if the client requests it, and verify the addon version and settings before normal play.

4. Check for and install addon updates

  1. Exit WoW, open GitAddonsManager, and select Refresh addons list and check for updates.
  2. Use the update button beside one addon when its tooltip says Perform upgrade, or select Upgrade all addons in the toolbar.
  3. Wait until the manager reports that the operation has finished, then start WoW and confirm the expected addon version still loads.
  4. Keep SavedVariables unless an addon's own upgrade instructions explicitly require a reset; that is where Auctioneer market history and BeanCounter records are stored.
Know the limits: GitAddonsManager does not search for addons and does not automatically detect addons installed manually without a .git repository. Only use clone URLs supplied by a trusted addon source, and keep backups because repair or update operations can replace local file edits.
