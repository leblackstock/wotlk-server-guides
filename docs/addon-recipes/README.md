# Addon Recipes

This directory contains validated, reusable addon setup recipes. These documents preserve working configurations without treating them as public Guide Hub pages or canonical addon-catalog entries.

## Recipes

- [WeakAuras Combat Cursor Ring and Flame Trail](weakauras-combat-cursor-flame-trail.md) — a combat-only cursor ring with a connected, tapered gold-and-orange trail for the supported WotLK WeakAuras fork.

## Recipe Standard

Each recipe should include:

- Exact client and addon compatibility.
- Reproducible setup steps using portable paths and names.
- Complete configuration or code blocks.
- Verification and safe removal instructions.
- Tuning guidance when the result is intentionally customizable.

Do not include account names, character-specific saved data, secrets, or local absolute paths. Promote a recipe to a player-facing guide only as a separate, explicitly reviewed change.
